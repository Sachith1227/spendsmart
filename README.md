# SpendSmart

A personal finance app built with Flutter and Firebase: track income and expenses, set monthly budgets and savings goals, and view spending analytics.

## Features

- Email/password and Google sign-in (Firebase Authentication)
- Per-user data synced to Cloud Firestore (works offline)
- Transactions with categories, payment methods and monthly recurring entries
- Monthly budgets, savings goals, analytics and in-app alerts
- CSV export

## Project structure

```
lib/
├── main.dart              # Entry point, Firebase initialisation
├── app.dart               # MaterialApp setup
├── firebase_options.dart  # Generated by FlutterFire CLI
├── core/                  # Shared, feature-independent code
│   ├── theme/             # Colours and app theme
│   ├── utils/             # Formatters and helpers
│   └── widgets/           # Reusable widgets and dialogs
├── data/                  # Data layer
│   ├── models/            # Transaction, budget and goal models
│   ├── services/          # Firebase Auth service
│   └── state/             # AppState (Firestore sync)
└── features/              # One folder per feature
    ├── auth/              # Welcome, login, register, auth gate
    ├── shell/             # Bottom-navigation shell
    ├── home/
    ├── transactions/
    ├── budgets/           # Budgets and savings goals
    ├── analytics/
    ├── notifications/
    └── profile/
```

Firestore data is stored under `users/{uid}/transactions`, `budgets` and `goals`. Access rules are in `firestore.rules`.

## Getting started

```bash
flutter pub get
firebase deploy --only firestore:rules
flutter run
```
